# Apple Skills Module

**Status:** Ready  
**Selected skills:** 20

This module contains a curated general-purpose subset of the supplied Apple skills.

## Usage

1. Read `SKILLS_INDEX.md`.
2. Choose the single skill or smallest set required by the task.
3. Read the selected `SKILL.md` completely.
4. Load only the references named by that skill and relevant to the current work.
5. Continue under JAP scope, safety, validation and reporting rules.

Do not load every Apple skill by default.

## Selection scope

Included skills cover:

- modern Swift language and API design;
- architecture, concurrency, Codable, testing and SwiftData;
- SwiftUI composition, layout, navigation, animation, gestures, Liquid Glass and performance;
- networking, authentication and cryptography;
- accessibility and localization;
- App Store readiness review.

Framework-specific skills such as HealthKit, CarPlay, StoreKit, RealityKit, CoreBluetooth and dozens of others remain outside this compact package. Add one later only when a real project requires it.

The original supplied ZIP was not modified.

# Roblox Studio Project Bootstrap

Before executing work, read in order:

1. `instructions/JAP.md`
2. `instructions/EXECUTION_FAST.md`
3. `PROJECT_PROFILE.md`
4. the primary Roblox Studio harness and only applicable additional harnesses from `PROJECT_PROFILE.md`
5. `instructions/modules/roblox/ROBLOX_STUDIO.md`
6. the direct task or active entries in `WORK_ORDER.md`
7. `instructions/modules/roblox/ROBLOX_SECURITY_STANDARD.md` when its activation conditions apply

If `PROJECT_PROFILE.md` is `bootstrap_required`, establish the exact experience target and authoritative source before editing. Record only verifiable facts.

Execute only explicit task scope. When the work order is invoked, run only `READY` tasks under its mode, limit and stop conditions. Update `PROJECT_STATE.md` and task statuses with verified facts only.

Do not edit both repository and Studio as independent sources. Do not create unrelated Instances or scripts. Do not commit, push, publish, change live configuration or operate on production data unless the profile and active task authorize the exact action.

Stop when the applicable acceptance criteria are evaluated. Return the JAP Agent Report and Roblox addendum.

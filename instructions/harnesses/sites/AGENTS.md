# Site Project Bootstrap

Before executing work, read in order:

1. `instructions/JAP.md`
2. `instructions/EXECUTION_FAST.md`
3. `PROJECT_PROFILE.md`
4. the primary Site harness and only applicable additional harnesses from `PROJECT_PROFILE.md`
5. the direct task or active entries in `WORK_ORDER.md`
6. only additional modules required by the task

If `PROJECT_PROFILE.md` is `bootstrap_required`, infer and record only verifiable technical facts needed for execution. Do not invent product decisions.

Execute only explicit task scope. When the work order is invoked, run only `READY` tasks under its mode, limit and stop conditions. Update `PROJECT_STATE.md` and task statuses with verified facts only.

Do not add dependencies, migrate data, commit, push, deploy, publish or change production configuration unless the profile and active task authorize the exact action.

Stop when the applicable acceptance criteria are evaluated. Return the JAP Agent Report.
